# ChartMaker - 图表制作

一个专业的数据可视化工具，支持创建柱状图、饼图和折线图。

![ChartMaker Screenshot](./screenshot.png)

## 🌟 功能特点

- 📊 **多种图表类型**: 柱状图、饼图、折线图
- 🎨 **精美设计**: 现代青色专业风格
- 🌍 **多语言支持**: 英语、中文、西班牙语、日语、韩语
- ⚡ **实时预览**: 输入数据即时更新图表
- 💾 **一键下载**: 导出PNG图片用于报告和演示

## 🚀 在线访问

**GitHub Pages**: https://kanshaowz.github.io/chartmaker/

## 🛠️ 技术栈

- HTML5 + CSS3
- JavaScript (原生)
- Chart.js 图表库
- Google Fonts (Inter字体)

## 📖 使用方法

1. 选择图表类型（柱状图/饼图/折线图）
2. 输入图表标题
3. 添加/编辑数据项
4. 选择配色方案
5. 点击下载按钮导出图表
